# FIXES

Log of problems faced and how they were fixed, so any person or agent can avoid repeating them. Add a row whenever a problem is resolved and commit it with the change.

| PROBLEM | FIX | CAUSE / OCCUR | DATE |
| ------- | --- | ------------- | ---- |
| Clerk webhook signature verification could pass or fail by accident | Mounted the webhook router ahead of `express.json()` with `express.raw`, and verify the exact bytes. The handler now rejects a non Buffer body outright | The handler verified `JSON.stringify(req.body)` after the global JSON parser had already run. Re-serialising does not reproduce the original key order, whitespace or unicode escaping. Occurs on every Clerk delivery | 10-08-2026 |
| Push broadcast to more than 100 devices failed entirely | Chunk messages into batches of 100 in `expo.service.ts`. A failing batch no longer aborts the rest | Every token was posted to Expo in one request. Expo caps a request at 100 messages. Occurs on any broadcast once more than 100 devices are registered | 10-08-2026 |
| Retired push tokens accumulated and were counted as recipients | Read the Expo tickets, collect `DeviceNotRegistered` tokens, and prune them straight after the send | Ticket responses were never inspected and `checkExpoReceipts` was never called. Occurs whenever a user uninstalls the app | 10-08-2026 |
| Render keepalive never ran in production | Guard now skips only under test and requires `HEALTHCHECK_URL` | The job returned early unless `NODE_ENV === 'test'`, the inverse of the intent. Present in both services. Occurs in every deployed environment | 10-08-2026 |
| `PUT /admin/documents/:id` rejected every valid payload | Validate updates against `DocumentSchema.partial()` | A local schema demanded a string `content` and a `tags` field, neither of which exists on a document. Occurs on every document update | 10-08-2026 |
| Helmet CSP image directive resolved to the string `undefined` | Derive the bucket URL from validated config | The directive read `process.env.AWS_S3_BUCKET_URL`, a variable defined nowhere. Occurs on every response | 10-08-2026 |
| Importing `@/utils/logger` before `@/config` crashed at startup | Removed the module scope `logger.info` call from `config/s3.ts` | `config/index.ts` re-exports `s3.ts`, which logged at import time, while the logger imports config. Circular import left the logger undefined. Occurs whenever a module reaches the logger before it reaches config | 10-08-2026 |
| Prisma logged every SQL statement and its parameters in production | Query logging is development only | The client was constructed with `log: ['query', ...]` unconditionally. Occurs on every query in every environment | 10-08-2026 |
| Email attachments could be fetched from any URL | Attachment URLs must be https on a host in `EMAIL_ATTACHMENT_HOSTS`, capped at 10 per message | Nodemailer fetches an attachment given as a `path`, and the value came straight from the admin request with no checks. Occurs on any email send with attachments | 10-08-2026 |
| Broadcast emails disclosed the whole recipient list | Recipients moved to `bcc` | Every address was passed in `to` and joined into one header. Occurs on any multi recipient send | 10-08-2026 |
| Readiness reported healthy during a Postgres outage | Probe MongoDB, Postgres and Redis, and fail the check if any one of them fails | The endpoint only checked Mongo and Redis. Postgres arrived with the notification merge and was never added, so every notification endpoint could be failing while a load balancer kept routing traffic | 10-08-2026 |
| Readiness could report healthy against a dead socket | Each probe now issues a real round trip: `admin().ping()`, `SELECT 1` and `PING`, in parallel with a 2 second timeout each | The check read `mongoose.connection.readyState` and `redisClient.isOpen`, which report what the driver believes about its socket rather than whether the server answers. Occurs on a network partition or an unresponsive server | 10-08-2026 |
| `KEYS` blocked the Redis event loop during cache invalidation | Replaced with a cursor based `SCAN` loop | `redisClient.keys()` traverses the whole keyspace in one blocking call. Occurs on every admin write | 10-08-2026 |
| `git commit` failed with `Unable to create .git/index.lock: File exists` | Confirmed no git process was running, then removed the stale `.git/index.lock` file | A git process was interrupted on 03-08-2026 and left the lock behind. Occurs on any git write in this repository until the lock is removed | 10-08-2026 |
